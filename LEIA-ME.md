# Perto de Você — pacote para GitHub Pages

Este pacote contém o site estático. Ele funciona sem servidor próprio, banco de dados ou instalação de dependências.

## Como publicar

1. Crie um repositório no GitHub ou abra um repositório existente.
2. Envie **index.html**, **favicon.svg** e **.nojekyll** para a raiz do repositório (não envie apenas o ZIP).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**. Selecione a branch principal e a pasta **/(root)**; depois salve.
5. Aguarde o endereço do site aparecer na mesma tela.

Para atualizar o guia, edite os dados dos estabelecimentos em `index.html` e envie o arquivo novamente. Confira os links externos e os horários antes de divulgar o site publicamente.
